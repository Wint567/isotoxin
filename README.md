# Isotoxin — Messenger Website UI

A static, responsive website interface for a messenger product, with a landing page and account-related screens.

**Stack:** HTML · CSS · Tailwind CSS via CDN · JavaScript

## Features

- Product and feature sections with mobile navigation.
- FAQ accordion with category filters.
- Mobile feature slider with dot navigation.
- Sign-in, registration, password recovery and reset page layouts.

## Run locally

Open `index.html` in a browser, or serve the repository with a static web server. An internet connection is needed for the Tailwind CDN and external font resources.

Account screens are available at `signin.html`, `signup.html`, `forgot.html`, `reset.html` and `notice.html`.

## Structure

- Root HTML files — page layouts.
- `css/index.css` — custom styles.
- `js/main.js` — navigation, FAQ and slider interactions.
- `public/` — images and icons.

## Scope

This repository demonstrates frontend layouts and interactions. It does not implement messaging, encryption, account storage or an authentication service.
